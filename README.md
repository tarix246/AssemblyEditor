Basically, I decided to make an assembly editor because vscode doesn't have a lot of features regarding assembly - by default white text, extensions aren't rich.
Since I have no idea how to make graphics, I simply told AI to make it for me with certain features. It features:
1. constants
2. general instructions
3. registers (rip is different color)
4. labels
5. jumps (both conditional and unconditional)
6. call/ret
7. stack operations
8. sections
9. nop instruction
10. brackets
11. comments

(all above is in different colors, and I probably forgot some of them)

Note that all of this was made for AT&T and Intel syntax, so ARM assembly will most likely not work.
Ctrl + (A,C,V,S) work too
